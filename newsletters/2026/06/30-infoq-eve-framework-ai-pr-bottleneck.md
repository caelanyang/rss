**AI Works, Pull Requests Don't: How AI Is Breaking the SDLC**

Michael Webster discusses the rise of headless AI agents and their impact on software delivery pipelines. Massive, AI-generated pull requests create a severe bottleneck for human reviewers and introduce persistent technical debt. Solution: test impact analysis and automated validation pipelines to verify agentic output without sacrificing stability.

AI 运行良好，但 Pull Request 却不尽如人意：AI 生成的 Pull Request 会给人工审核造成严重瓶颈，并引入持续存在的技术债务。解决方案：测试影响分析和自动化验证流程。

**Understanding ML Model Poisoning: How It Happens and How to Detect It**

Covers data poisoning threats including label flipping, backdoors, clean-label poisoning, and gradient manipulation. Reviews real-world incidents, challenges of detecting poisoned data, and practical defenses for securing ML training pipelines.

机器学习模型投毒：数据投毒威胁包括标签翻转、后门、干净标签投毒、梯度操纵。保护机器学习训练流程的实用防御措施。

**Rules for Understanding Language Models**

Naomi Saphra discusses 5 rules governing LLM behavior — why LLMs act like populations rather than individuals, how tokenization creates semantic blind spots, and how sycophancy works (models match user biases and demographics — even guessing political views from favorite sports teams).
