AI/ML 和数据工程：Pinecone 发布 Nexus 引擎，将业务上下文编译为 AI Agent 可用的结构化数据。Meta 的非侵入性脑机接口 Brain2Qwerty 达到 61% 准确率。Dolt 2.0（版本控制 SQL 数据库）发布，支持自动存储清理和压缩。

DevOps：AWS 推出 CloudFormation Express 模式加速基础设施部署。Ben O'Mahony 展示如何用 OpenTelemetry 原生标注 AI Agent 行为，跟踪用户的操作（接受、拒绝、重新生成代码修复）作为隐式标签，将前沿模型能力蒸馏为本地 SLM。

PostgreSQL 在生产 AI Agent 中的应用——Gwen Shapira 展示利用 JSONB 解析和 HNSW 向量索引为 LLM 提供上下文，用向量量化加速查询 4 倍管理 Agent 记忆。

治理：Sarah Wells 讨论治理与软件架构的关系——治理通过建立流程最小化系统复杂性、提高安全性、减少重复任务，目标清单帮助工程师减少执行压力。

SRE 行业调查：78% 的团队表示客户先于他们发现事故，40% 的工程时间浪费在故障排查而非推动路线图上。
