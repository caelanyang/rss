## 1. Microsoft AI 发布 MAI-Cyber-1-Flash 网络安全模型

Microsoft 发布首个网络安全专用模型 MAI-Cyber-1-Flash，采用稀疏 MoE 架构，137B 总参数 / 5B 活跃参数。该模型在 CyberGym 基准上达到 95.95% 的准确率，可处理高达 90% 的 MDASH 安全任务，仅将最难的 10% 留给 GPT-5.4。在 Sakana 的 Fugu-Cyber 发布一周后，Microsoft 以更高的 CyberGym 分数回应——专业网络安全模型的竞赛已成为每周排行榜。

## 2. Kimi AI 开源 AgentENV

Moonshot 的 Kimi 团队与 kvcache-ai 开源了 AgentENV（AENV），采用 MIT 许可证。这是一个用于大规模运行智能体环境的分布式平台，解决了智能体 RL 中被忽视的一半问题——环境吞吐量。AgentENV 驱动了 Kimi K3 的智能体 RL 训练。

## 3. Perplexity 发布 pplx CLI

Perplexity 发布了 pplx，一个单二进制 CLI 工具，将搜索 API 结果以 JSON 格式输出到终端，专为编码智能体设计。定价为每 1000 次请求 5 美元。这意味着 Perplexity 将其搜索定位为编码智能体循环内的默认检索工具。

## 4. Black Forest Labs 发布 FLUX 3

FLUX 3 是一个 32B 多模态流模型（扩散 Transformer），联合学习图像、视频和音频到同一世界表征中——可生成 20 秒带原生音频的视频、4MP 图像，并通过 FLUX 3 x mimic 预测机器人动作。生成模型和世界模型正在融合——同一个可以生成媒体的骨干网络也可以驱动机器人。

## 5. Datalab Marker 2 文档解析基准

Marker 2 在 olmOCR-bench 上得分 76.0，处理速度 2.9 页/秒——匹配 Gemini/MinerU 质量的同时速度快约 5 倍，同时在得分和吞吐量上超越 MinerU 和 Docling。
