Anthropic 豪掷 450 亿美元与 Nscale 签算力大单 ↗

Anthropic 与云基础设施商 Nscale 达成 450 亿美元算力协议，成为其近期一系列大规模算力采购中最新且最大的一笔。这意味着 Anthropic 在不依赖单一云厂商的前提下正快速构建自己的独立算力护城河，对 Claude 系列模型的训练与推理能力将产生直接加速效果。

Amazon 三倍加码英伟达芯片采购，AI 算力军备升温 ↗

亚马逊宣布在未来两年内追加 200 万块英伟达 GPU，总订单规模翻三倍，理由是 AI 推理需求暴增。此次扩购不仅是硬件采购，更涉及双方战略合作延伸，预示着云计算与 AI 推理市场的竞争即将进一步白热化。

Anthropic 在 GitHub 上开放了 Claude Cowork 与 Claude Code 的官方社区插件市场镜像仓库，每晚从内部审核流水线同步更新。开发者现可通过官方渠道提交、发现和安装社区插件，标志着 Claude 插件生态正式进入有组织的开放平台阶段。

开发者 MadsLorentzen 开源了一套基于 Claude Code 的 AI 求职框架，可自动评估职位匹配度、定制简历、撰写求职信并模拟面试准备。整个流程本地运行、数据自持，是 Claude Code 用于个人生产力场景的典型实战案例。

Apache Maka 孵化：本地优先、可恢复的 Agent 工作区 ↗

Apache 基金会正在孵化 Maka——一个本地优先的 AI Agent 工作区，将模型消息、工具调用、权限决策等所有事件以追加日志方式记录，支持执行恢复。对开发者而言，这意味着 Agent 任务可调试、可回溯、可审计，解决了当前 Agent 框架「运行完就消失」的黑盒痛点。

Lovable CTO：SaaS 的未来是 Agent 可直接调用的能力层 ↗

Lovable CTO Fabian Hedin 接受专访，阐述公司正从 AI 网页应用构建器向 MCP 驱动的「能力层」转型。他认为未来 SaaS 的核心竞争不是 UI，而是能否让 AI Agent 直接调用你的产品能力。这一判断对正在考虑产品方向的独立开发者和 SaaS 团队极具参考价值。
